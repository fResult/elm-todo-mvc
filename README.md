# ELM Todo MVC

A [TodoMVC](https://todomvc.com) application built with the Elm programming language.

### Prerequisites

- **ELM Compiler** (v0.19 or higher) - [Installation Guide](https://guide.elm-lang.org/install.html)

## Development

1. **Start the Application**
    Run the Elm built-in server by executing the following command in your terminal:
    ```bash
    elm reactor
    ```

2. **Access the application**
    Open your browser and navigate to the local server address:
    👉 <http://localhost:8000/src/Main.elm>
